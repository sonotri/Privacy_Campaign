# BLACK SWAN ROULETTE — CONSENT TEST

사용자가 제공한 이미지와 같은 스타일의 개인정보 카드를 사용하는 선택 체험용 웹 게임입니다. 외부 패키지, 서버 데이터베이스, 분석 추적 없이 동작합니다. 사용자가 교환할 카드의 내용을 직접 작성합니다.

## 실행

- 가장 간단한 실행: `dist/index.html`을 브라우저로 엽니다.
- 로컬 서버: 프로젝트 폴더에서 `node server.cjs`를 실행하고 출력된 주소에 접속합니다. 필요하면 `PORT` 환경 변수로 포트를 지정할 수 있습니다.
- 배포 대상은 `dist/`입니다. HTML, CSS, JavaScript와 이미지가 모두 포함된 정적 사이트입니다.

## 게임 흐름

시작 → 설명 → 룰렛에서 회전·미당첨·재도전 → 카드 선택·작성·교환/중단 또는 JACKPOT → CONSENT TEST → 교환 기록 → COMBINING DATA → 선택별 연결 사례 → 5초 간격의 7장 엔딩 → 게임 종료.

- 처음에 SPIN 1회를 제공합니다. 첫 두 회는 세 심볼이 서로 겹치지 않도록 추첨합니다. 세 번째 회부터 세 심볼을 독립적으로 균등 추첨하며 3개 일치 확률은 1/9입니다.
- 닉네임·관심사 각 1회, 생년월일·학교/소속 각 2회, 이메일 주소·거주지 정보 각 3회로 교환합니다. 처음 받은 1회 포함 최대 13회입니다. ★는 게임 내 교환 가치입니다.
- 한 번에 한 장, 카드별 한 번만 교환됩니다. 다른 카드를 누르면 선택이 바뀌며, 선택만 한 상태에서 중단하면 소비되지 않습니다. 교환 즉시 룰렛으로 돌아오며, 룰렛 아래에 교환 내역이 표시됩니다.
- 미당첨 때 별도 결과 화면으로 이동하지 않고 마지막 세 심볼과 다음 행동을 같은 룰렛에서 확인합니다. 남은 SPIN은 곧바로 다시 돌릴 수 있습니다.
- 받은 SPIN을 모두 소진한 뒤 다음 카드를 교환합니다. 두 번째 실패부터 기회가 소진되고 2·3회 카드가 남아 있으면 검은 백조의 BONUS 제안이 표시됩니다. BONUS는 카드로 받는 총횟수이며 추가 가산이나 확률 상승이 아닙니다.
- 당첨, 자발적인 중단, 또는 카드와 SPIN 소진으로 종료합니다. 당첨 후 남은 SPIN은 사용하지 않습니다. 이미 교환한 카드는 당첨 여부와 무관하게 선택 순서대로 사용 내역에 남습니다.
- 행사 상품 당첨 화면은 운영진에게 보여주는 안내입니다. 실제 상품 종류·재고·배부는 운영진이 관리하며, 사이트는 상품 지급이나 중복 수령 방지를 자동 처리하지 않습니다.
- 최종 화면은 직접 작성한 값 → 추정 가능한 결론 → 사용 맥락과 영향 순서로 보여줍니다. 선택한 카드만 사용하며, 신원·장소·취향 중 최대 3개의 서로 다른 사례를 직접 넘겨 읽습니다. 0장·1장은 별도 상태입니다. 실제 계정 검색, 신원 확인 또는 위치 추적은 하지 않습니다.
- 결합 위험도는 교환 가치의 합산이 아닌 교육용 시나리오 단계(0~5)입니다. 닉네임+학교/소속+생년월일은 5단계 예시입니다. 카드에 없는 정보를 사실로 확정하지 않으며 사례별 추정의 한계를 함께 표시합니다.
- 사용자가 제공한 엔딩 원문은 7개 장면으로 나누어 전부 유지합니다. 각 장면은 5초 뒤 자동 전환되고 진행 막대가 시간을 보여줍니다. 이야기 건너뛰기를 선택할 수 있으며, 마지막 장면 뒤에는 종료 화면으로 자동 이동합니다. 종료 화면에서 이야기를 다시 보거나 새 게임을 시작할 수 있습니다.
- 새로고침·다시 시작은 게임 상태를 초기화합니다. 게임 선택 내역은 브라우저 메모리에만 존재하며 서버에 전송되지 않습니다.

## 직접 작성하는 카드

- 교환할 카드 한 장을 고르면 해당 항목의 작성란이 나타납니다. 빈 값으로는 교환할 수 없으며 직접 작성한 내용으로만 교환합니다. 예시 자동 입력 기능은 없습니다.
- 닉네임·관심사·학교/소속·이메일 주소·거주지 정보는 길이 제한이 있는 텍스트, 생년월일은 1900년부터 오늘까지의 유효한 날짜입니다. 이메일 주소는 기본 형식을 검사하며, 거주지 정보는 상세 주소 대신 시·구·동 수준을 안내합니다.
- 위치 권한을 요청하거나 입력한 이메일 주소로 계정을 조회하지 않습니다.
- 입력은 현재 페이지의 메모리에만 있습니다. 서버 전송, localStorage/sessionStorage, 쿠키, 파일 저장에 사용하지 않습니다. WebMCP 상태 조회에도 입력한 값을 포함하지 않습니다.
- 다른 카드 선택 또는 교환 취소 시 미교환 입력을 지웁니다. 이미 교환한 내용만 마지막 기록과 연결 사례에 사용합니다. 입력값은 HTML이 아닌 텍스트로 표시됩니다.
- 새로고침과 페이지 이탈 시 입력과 게임 기록을 초기화합니다. 연결 사례에서 마지막 이야기로 넘어가면 입력을 삭제합니다. 엔딩은 고정된 문장만 사용합니다.
- 교육용 연결 결과는 사용자가 제공한 항목을 시나리오 문장에 넣는 방식이며 실제 인물이나 계정을 조회하지 않습니다. 제공된 내용의 진위를 검증하지 않습니다.

## 조작 및 접근성

터치/마우스, Tab·Enter, 룰렛 화면의 Space를 지원합니다. Blackvoid6의 완성곡 4곡이 첫 사용자 조작 후 순서대로 재생됩니다. 짧은 합성 루프는 제거했습니다. 게임 화면 전환·음소거·탭 전환·새 게임에서는 음악의 재생 위치를 유지합니다. 곡이 끝나면 다음 곡으로 넘어가며 마지막 곡 뒤에만 처음 곡으로 돌아옵니다. 효과음은 Web Audio를 사용합니다. SOUND 버튼은 음악과 효과음을 함께 끕니다. 숨긴 탭에서는 멈춥니다. SPIN이 0이 되고 교환 가능한 카드가 있으면 중앙 모달에서 큰 `카드로 기회 교환` 버튼과 종료 선택을 보여줍니다. 모달은 키보드 포커스를 유지하고 Escape로 교환을 중단할 수 있습니다. 남은 SPIN이 있거나 카드가 소진된 경우에는 뜨지 않습니다. 반전과 엔딩에서는 음악·효과음·상단 조작부를 없애 읽기에 집중하도록 합니다. 전체 화면, 모션 줄이기 설정을 지원합니다. 정보 연결 결과는 이전·다음 버튼 또는 좌우 방향키로 이동합니다. 마지막 이야기는 5초 간격으로 자동 진행되며 바로 건너뛸 수 있습니다. 짧은 연결 연출도 바로 건너뛸 수 있습니다.

## 파일

- `dist/index.html`: 시작 화면 및 문서 구조
- `dist/style.css`: 네온 UI·반응형·애니메이션
- `dist/briefing.css`: 게임 안내와 시작 버튼
- `dist/experience.css`: 규칙·카드 교환·프로필 결과 화면
- `dist/story.css`: 연속 룰렛·반전·연결 사례·엔딩 읽기 화면
- `dist/story.js`: 가상 카드 값·선택별 추론 사례·엔딩 원문
- 마지막 이야기 문구는 `dist/story.js`의 `const chapters = [...]` 배열에서 수정합니다.
- `dist/personal-data.js`, `dist/personal-data.css`: 브라우저 메모리 기반 작성·검증·카드 표시
- `dist/soundtrack.js`: 완성곡 플레이리스트·효과음·음소거·재생 위치 유지
- `dist/assets/music/`: 게임에 통합된 MP3 4곡과 원본 라이선스
- `dist/game.js`: 상태 전환·추첨·카드 교환·교육용 조합 결과
- `dist/assets/`: 룰렛·심볼·개인정보 카드 이미지
- `server.cjs`: 의존성 없는 로컬 정적 서버

선택적으로 브라우저가 WebMCP를 지원하면 상태 조회, 현재 화면의 행동, 카드 선택 도구를 등록합니다. UI와 동일한 검증을 거쳐 동작합니다.
